算法说明

图像感知通道

  1. 前景分割：以四角像素估计背景色，用中位数 + 3×1.4826×MAD 的鲁棒阈值分离主体，中值滤波去噪后保留最大连通域。
  2. 轮廓指纹：把前景掩膜等比归一化到 16×16 网格（保持长宽比、居中放置），得到 256 位轮廓指纹，用 Dice 系数比对；再配合包围盒填充率（方块≈1.0、圆≈0.79、三角≈0.5）区分「轮廓相近但形状不同」的物品。
  3. 颜色直方图：只取 HSV 的色相 H，做 16 维环形软分箱直方图，用直方图相交率衡量一致性。只取色相是实测结论：饱和度会被曝光直接带动（同一红色物体曝光 +12% 时前景饱和度均值从 174 掉到 162），导致明明同色的直方图相交率只剩 0.065；改用色相后回升到 0.92。
  4. 主色一致性：用加权 H/S/V 距离补充「深红 vs 浅红」这类亮度差异。
  5. 整图 pHash：DCT 低频 64 位指纹，仅作为「疑似同一张照片」的弱提示（权重 10%）。实测它对拍摄距离过于敏感：同一方块换尺度后汉明距离 24~32，而换成圆形也只有 21，几乎没有区分度，因此不作为主通道。

文本标签通道

  1. 中文分词：单字 + 相邻双字同时入袋，并做同义词归一化（"蓝牙耳机"→"耳机"、"一卡通"→"校园卡"）。
  2. TF-IDF 余弦：在「目标 + 全部候选」语料上拟合 IDF，避免单词语料导致权重退化。
  3. 标签重合度：Dice 系数 + 字符二元组模糊等价（"黑色耳机" ≈ "耳机"）。
  4. 地点语义：字符串包含关系、地点提示词命中（教学楼/图书馆/食堂…）与 token 重合。
